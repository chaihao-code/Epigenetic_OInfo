# Developmental redundancy cores and synergistic triplet trajectories

Shared core entry point: `script/hoi_code/compute_redundancy_core.py` at the repository root. Executable project scripts use descriptive names under `scripts/`. Historical supplied scripts in the local `provenance/` directory are excluded from this GitHub export.

Inputs are current full-order observed O-information CSVs from mouse_preimp and mouse_after_E11.5 (7 early + 66 later samples). Restrict to eight shared signals before core selection, excluding H2A.Z in early data and H3K4me2/H3K9ac in late data. Expect 40 blocks and all 219 subsets of orders 3–8 per sample/block.

For each order 3–7, choose the subset with maximum O-information. Compare it with all k × (8-k) same-order subsets formed by replacing one signal. Require positive O-information and modified z > 2.5, where z = 0.6745 × (target - median(background)) / (MAD(background) + 1e-12). Compare one- and two-component Gaussian mixtures by BIC (seed 0, five starts). Accept a one-component preference; for two components, require the type-II ANOVA sum-of-squares fraction attributed to the incoming signal to exceed 0.5. Promote an accepted order-7 subset to order 8 if full-set O-information is greater; prune proper subsets of accepted larger cores. This is the supplied replacement-background algorithm, with deterministic background ordering and CLI/data-format support. It does not assign permutation p-values or FDR to cores.

Synergistic triplets use the current original-only BH56 results (10,000 permutations, O-information < 0, FDR <= 0.05) already validated in `../synergistic_triplets/`. The trajectory program reads that analysis's per-sample count table.

Figures use the same 7 early samples and five common late tissues at every stage (Forebrain, Midbrain, Hindbrain, Heart, Liver). Match the supplied trajectory layout: average ICM and TE under E3.5; show E11.5–P0 after an inter-period gap, with later day spacing. Lines connect E3.5 to E11.5 across that gap. Cores are computed for all 66 late samples, but figures use the fixed common-tissue panel for comparability. Zero-core samples are included. Error bars are SEM calculated from sample SD (ddof=1), across tissues in late stages and across ICM/TE at E3.5; these are not biological replicate uncertainty estimates. Single-sample SEM is zero.

Output figures (PDF/PNG):
- `plots/synergistic_triplet_mark_trajectories.pdf`
- `plots/redundancy_core_mark_trajectories.pdf`

Style: 18 × 6 cm, Arial 8 pt, title 10 pt; current cool/warm palette with H3K36me3 highlighted as a pure-black 2.6 pt line, 4.2 pt markers and top drawing order. The y-axis includes zero.

Tasks and provenance: `inputs/analysis_manifest.json`, `inputs/tasks.tsv`; per-sample cores, full per-order diagnostics and metadata under `results/<sample>/`. Combined cores and zero-inclusive sample counts are generated by the plot job. The manifest is marked complete only after all 73 samples and both figures validate.

Execution:
```bash
sbatch scripts/compute_redundancy_cores.slurm
sbatch --dependency=afterok:COMPUTE_JOB_ID scripts/plot_trajectories.slurm
```
To redraw completed results with the project Python environment:
```bash
python scripts/plot_synergistic_triplet_trajectories.py
python scripts/plot_redundancy_core_trajectories.py
```

Combined horizontal version: run `python scripts/plot_combined_trajectories.py` after
both trajectory tables exist. Output: `plots/combined_triplet_core_trajectories.{pdf,png}`.
Exact size 18 × 6.5 cm, all text Arial 8 pt, two panels side by side and one shared
four-column (two-row) legend below. Both panels show all 13 vertical stage labels
using categorical stage spacing; the individual figures retain their original
day-based spacing. Means/SEM are unchanged. H3K36me3 uses a 1.1 pt black line
with 2.8 pt markers. Validation checks all label bounds, tick overlap and separation
of the bottom legend from the axis labels before saving.

Full-signal combination occurrence figures are maintained separately under
[`full_signal_occurrence/`](full_signal_occurrence/README.md): all nine early
signals and all ten late signals, with cores recomputed for those universes.
That analysis follows the supplied triplet occurrence script's sign-only
criterion (O-information < 0, no FDR filter), rather than the BH56 criterion of
the eight-signal trajectories described above. It provides four top-25 bar and
combination-matrix plots plus an 18 x 15 cm combined layout, all text 8 pt.
