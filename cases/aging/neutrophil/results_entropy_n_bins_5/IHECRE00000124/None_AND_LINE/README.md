The parent case's sample manifests, existing four-column `.bp` tracks (`chr start end signal`) and unchanged genome-specific annotation masks. Comparison/plot programs also read the existing result CSV/TSV files named in their source.

## Usage

Run commands from the repository root and set `EPINFO_ROOT` to that root. Read `cases/aging/neutrophil/results_entropy_n_bins_5/IHECRE00000124/None_AND_LINE/IHECRE00000124_None_AND_LINE_entropy_all_subsets.csv` with pandas (`sep=","`; gzip compression is inferred). Existing result tables do not execute a pipeline.
