# 整理说明（按最新要求更新）

## 固定区间与新的 demo

原来划分的基因组窗口、功能/重复序列类别和已有 bins 文件继续提供，作为恒定输入。不会再用裁剪的一小段坐标代替原分析区间。已撤掉之前的 1,024 窗口小鼠示例。

新的 `demo/` 使用人的甲状腺衰老案例：健康供体 CEMT0098，30 岁女性，六条 histone 加一条甲基化信号，并使用匹配的 Input。提供的是该供体完整的原格式数据：原 hg38 1 kb 网格共 3,209,513 行，原程序保留其中 2,875,012 个常染色体窗口用于计算；原 40 个注释类别及其成员定义不变。另保留六位健康供体的配置。

从完整 bigWig 开始的步骤是：按原固定窗口分箱 → 六条 ChIP/Input 归一化（甲基化不除 Input）→ 原全局五状态离散化 → 原类别分组与最多 100,000 loci 的抽样 → global O-information 与 10,000 次置换 → 相同矩阵上的 local O-information。每一步的用途、输入、输出、文件名、实际检验记录见 `demo/README.md`。

原格式为无表头四列 `chr start end signal` 的 `.bp`；六条 histone 归一化后以 `.divInput.bp` 结尾。压缩输入是原完整预处理文件的副本。完整 bigWig 本机路径及下载来源记录在 `demo/input/bigwig_sources.tsv`；甲基化的公共源实际是 CpG BED.gz，其转换后的 bigWig 单独标明，不能将该下载文件直接改名为 bigWig。

## 计算入口、置换和 FDR

唯一 O-information 数值核心为 `common/02_oinformation/compute_hoi_oinfo.py`；各案例同名文件仅转发。原不带置换的熵计算/熵转 O-information 程序及旧提交入口已删除，原 local 独立公式也改为调用同一核心。

协同三元组的新计算默认 **10,000 次置换**，保留 `n_max=100000` 的原基因组 loci 抽样上限。两者是不同参数。对选定完整检验族的全部下尾 P 做 BH，之后才要求 Ω<0 且 q≤0.05。七信号每样本/类别为 35 项；B 细胞原每样本 1,400 项与全局 23,800 项也可显式选择。不会先筛负值再做 BH。

甲状腺 demo 默认展示原七信号全体系的置换检验；通用三元组/FDR 演示是 `--triplets` 可选项，不冒充新的甲状腺生物学结论。

## local 与区间的关系

固定注释类别始终完整保留。原全局算法可能在大类别中取最多 100,000 loci；新的计算保存实际抽样坐标。共享核心导出的 local 值使用同一批 loci，逐类别检验 local 均值与 global Ω 一致，避免混淆不同位置集合。原六供体的完整类别 local 回归输入仍放在案例目录，二者用途在英文 README 中分开说明。

## 说明与验证

所有实际目录均提供英文 `README.md`，解释用途、输入、使用方式和输出；不向软链接指向的原始工作区写说明文件。旧参考结果保留其真实历史置换次数，不会被改标签成 10,000 次的新运行。

七项科学检查覆盖已知协同/冗余、local/global 一致性、状态编码、BH 检验族与默认参数。已提交完整甲状腺 bigWig demo 作业；实际运行结果和差异记录以 `demo/results/from_bigwig/validation.json` 为准。原始数据、原有正式队列结果和 GitHub 远端均未被改写；本次只运行明确标注的新 demo。

## 旧甲状腺数值的已知复现边界

远端已有 QC 报告明确记载：论文旧存储结果使用的部分 histone divInput 输入位于已失效磁盘，现有文件不能逐值复现那些旧数值。报告位于 `cases/aging/thyroid/deconvolution/results/qc/hoi_recompute_validation.md` 与 `step9_recomputed_slope_divergence.md`。本 demo 验证现有完整 bigWig 与现有完整 bins 两条路径的可重复计算，不将其冒称为论文旧数值或原六供体年龄效应的逐值复现；旧表保持原样，差异另存。
